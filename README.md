# Sriharsha Nemalikonda Portfolio

Static portfolio website for GitHub Pages.

Live site: <https://nsriharsha04.github.io/portfolio/>

## What is included

- `index.html` - single-page portfolio content
- `static/css/style.css` - responsive styling
- `static/img/` - company and certification logos
- `resume/Resume.docx` - downloadable resume linked from the hero section

## GitHub Pages Hosting

This repository is ready to host from GitHub Pages with no build step.

1. Open the GitHub repository settings.
2. Go to **Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select branch **main** and folder **/**.
5. Save.

The site will be available at:

```text
https://nsriharsha04.github.io/portfolio/
```

## Local Preview

Because this is a static website, you can open `index.html` directly in a browser or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
